About Scifusion

Scifusion is a free, open science library for Classes 6 to 12. It covers 172 chapters and 344 topics with 688 worked examples and 1032 practice questions.

What's inside

  • Every chapter of the NCERT/CBSE science syllabus for Classes 6–10, plus separate Physics, Chemistry and Biology books for Classes 11–12.
  • Topic pages with a summary, key points, key terms, formulas where relevant, and at least two worked examples.
  • Practice — MCQs with explanations and short-answer questions with model answers.
  • A randomised quiz for every subject, and printable notes for offline study.

How it is built

All content is hand-written as plain Python data in tools/data/. A small generator (tools/build.py) validates the data and produces this site in docs/ plus Markdown books in books/. There are no trackers, no accounts and no external CDNs — the site works offline.

Contributing

  1. Edit or add a subject file in tools/data/ (copy an existing one as a template).
  2. Run python3 tools/build.py — it checks that every topic has at least two examples and three questions with answers.
  3. Commit both the data change and the regenerated site.
