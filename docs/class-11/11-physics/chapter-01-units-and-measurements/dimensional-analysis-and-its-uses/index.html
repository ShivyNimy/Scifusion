Dimensional Analysis and Its Uses

Dimensional analysis checks equations, derives relations and converts units, but cannot determine dimensionless constants.

2 worked examples · 3 practice questions

Key points

  • Only quantities with the same dimensions can be added or equated.
  • Dimensions of both sides of a valid equation must match.
  • Dimensional analysis can predict the form of a physical relation up to a dimensionless constant.
  • It cannot handle trigonometric, exponential or logarithmic functions directly.
  • Unit conversion uses the ratio of old to new units.

Worked examples

Example 1 Period of a pendulum

Assuming T depends on length l and g, dimensional analysis gives T ∝ √(l/g). The missing factor 2π cannot be found this way.

Example 2 Checking the wave equation

v = fλ: [L T−1] = [T−1][L], which is consistent.

Practice questions

Try each question before opening the answer.

  1. MCQ Dimensional analysis cannot determine:
    A. Dimensionless constantsB. Unit consistencyC. Dependence on variablesD. Dimensional formulas
    Show answer

    Answer: Dimensionless constants

    Dimensionless numerical factors are invisible to it.

  2. MCQ Which of these is dimensionless?
    A. StrainB. ForceC. VelocityD. Pressure
    Show answer

    Answer: Strain

    Strain is a ratio of lengths, so it has no units.

  3. Short answer Use dimensional analysis to find the dimensions of pressure.
    Show answer

    Pressure = force/area = [MLT−2]/[L2] = [M L−1 T−2].
