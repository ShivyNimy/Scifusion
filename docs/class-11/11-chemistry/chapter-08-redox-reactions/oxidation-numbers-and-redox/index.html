Oxidation Numbers and Redox

Redox reactions involve changes in oxidation state. Oxidation numbers track electron transfer.

2 worked examples · 3 practice questions

Key points

  • Oxidation is loss of electrons (increase in oxidation number); reduction is gain.
  • Oxidation numbers follow rules: pure elements 0, oxygen usually −2, hydrogen usually +1.
  • Disproportionation: one element is simultaneously oxidised and reduced.
  • Oxidising agents are reduced; reducing agents are oxidised.
  • Balancing redox reactions uses the ion-electron method.

Worked examples

Example 1 Oxidation number of Mn in KMnO4

+1 + x + 4(−2) = 0 gives x = +7.

Example 2 Chlorine in bleach

Chlorine (0) in Cl2 disproportionates to Cl− (−1) and ClO− (+1) in alkaline solution.

Practice questions

Try each question before opening the answer.

  1. MCQ Oxidation involves:
    A. Loss of electronsB. Gain of electronsC. No changeD. Gain of protons
    Show answer

    Answer: Loss of electrons

    Oxidation number increases as electrons are lost.

  2. MCQ The oxidation number of oxygen in most compounds is:
    A. −2B. +2C. 0D. −1
    Show answer

    Answer: −2

    Oxygen is usually −2 except in peroxides.

  3. Short answer Find the oxidation number of sulphur in H2SO4.
    Show answer

    2(+1) + x + 4(−2) = 0 gives x = +6.
