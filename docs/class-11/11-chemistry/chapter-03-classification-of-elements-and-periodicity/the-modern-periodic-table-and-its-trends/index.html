The Modern Periodic Table and Its Trends

Elements are arranged by atomic number. Position determines properties, and trends recur periodically.

2 worked examples · 3 practice questions

Key points

  • Periods are horizontal rows; groups are vertical columns.
  • Elements in a group have the same valence electron configuration.
  • Metallic character decreases across a period and increases down a group.
  • Anomalies exist, such as the similar chemistry of lithium and magnesium (diagonal relationship).
  • The table separates s, p, d and f blocks by the subshell being filled.

Worked examples

Example 1 Diagonal relationship

Lithium and magnesium show similar chemistry because of comparable charge/radius ratios, even though they are in different groups.

Example 2 Noble gas placement

Group 18 elements have complete octets and very high ionisation energies, giving them their characteristic inertness.

Practice questions

Try each question before opening the answer.

  1. MCQ Elements in the same group have the same:
    A. Number of valence electronsB. Atomic massC. Number of shellsD. Atomic radius
    Show answer

    Answer: Number of valence electrons

    Group number reflects valence configuration.

  2. MCQ Metallic character ______ down a group.
    A. IncreasesB. DecreasesC. Stays constantD. Vanishes
    Show answer

    Answer: Increases

    Atoms lose electrons more easily as size increases.

  3. Short answer Why does electronegativity increase across a period?
    Show answer

    Effective nuclear charge increases while atomic size decreases, so atoms attract bonding electrons more strongly.
