Polarisation and Resolving Power

Polarisation shows light is transverse. Optical instruments have limits on resolution set by diffraction.

2 worked examples · 3 practice questions

Key points

  • Polarisation restricts oscillations to one plane.
  • Brewster's law: tan θp = n gives the polarising angle.
  • Polaroids and polarising filters can block specific orientations.
  • Resolving power depends on wavelength and aperture diameter (Rayleigh criterion).
  • Polarised sunglasses reduce glare from horizontal surfaces.

Worked examples

Example 1 Polarising sunglasses

Reflected glare is partly polarised horizontally; vertical polarising filters block it, reducing glare.

Example 2 Brewster angle for glass

For n = 1.5, θp = tan−1(1.5) ≈ 56.3°, at which reflected light is fully polarised.

Practice questions

Try each question before opening the answer.

  1. MCQ Polarisation shows light is:
    A. TransverseB. LongitudinalC. MechanicalD. A particle beam
    Show answer

    Answer: Transverse

    Only transverse waves can be polarised.

  2. MCQ Polaroid films work by:
    A. Blocking one polarisation directionB. Reflecting all lightC. Refracting lightD. Absorbing all colours
    Show answer

    Answer: Blocking one polarisation direction

    They transmit only oscillations along one axis.

  3. Short answer What is Brewster's angle?
    Show answer

    The angle of incidence at which reflected light is completely polarised, given by tan θp = n.
