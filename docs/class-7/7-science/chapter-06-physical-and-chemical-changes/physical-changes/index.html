Physical Changes

A physical change alters shape, size or state without forming a new substance, and is usually reversible.

2 worked examples · 3 practice questions

Key points

  • Melting wax, folding paper, dissolving sugar, cutting wood and breaking glass are physical changes.
  • No new substance is formed, so the chemical composition stays the same.
  • Physical changes can usually be reversed by changing conditions.
  • The mass of the material is conserved.

Worked examples

Example 1 Wax and candle

Melting wax is a physical change because the wax can be re-solidified; the appearance changes but the substance is still wax.

Example 2 Dissolving salt

Salt dissolves in water but the salt can be recovered by evaporation. No new substance is formed.

Practice questions

Try each question before opening the answer.

  1. MCQ Which is a physical change?
    A. Melting of iceB. Burning of coalC. Rusting of ironD. Baking a cake
    Show answer

    Answer: Melting of ice

    Melting changes state but not chemical identity.

  2. MCQ A physical change is usually:
    A. ReversibleB. PermanentC. ChemicalD. Irreversible
    Show answer

    Answer: Reversible

    Most physical changes can be reversed.

  3. Short answer Give two examples of physical changes in daily life.
